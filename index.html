Fantasy API Worker

A personal, single-user tool that prepares fantasy football and contest-research summaries, and a monthly household rent summary, and emails them to its owner.

What it is

Fantasy API Worker is a private program that runs locally on its owner's own computer. It assembles fantasy sports information into a written report and delivers that report by email to the same person who runs it.

It is not a product, a service, or a website. There is no sign-up, no account to create, and no version hosted for anyone else. This page exists because Google requires an application using Gmail authorization to publish a home page, a privacy policy, and terms of service.

What it does with Gmail

  • Sends report emails from the owner's Google account to that same account.
  • Confirms that a message it just sent actually appears in that account's Sent mail, so a delivery is never recorded as successful without evidence.
  • Reads the one-time sign-in code the owner's apartment resident portal emails to the owner, only right after the tool itself asked the portal for one.

It does not browse the mailbox, read unrelated messages, or contact anyone else.

What it does with Google Sheets

It records each month's rent split in the owner's own rent spreadsheet (and a private test copy it creates), then reads the figures back to check them. It edits no other spreadsheet.

Not advice

Reports are informational. Nothing produced by this tool is financial, wagering, or professional advice, and no outcome is guaranteed. The tool places no bets, submits no contest entries, and performs no transactions.
