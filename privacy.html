Privacy policy

Fantasy API Worker · last updated 26 September 2026

Fantasy API Worker is a private program run by one person on their own computer, for their own use. It has no other users, no server, and no operator other than its owner.

Who this covers

The only Google account the program ever touches is the owner's own account, which is also the only account authorized to use it. If you are reading this without being that person, the program holds no data about you.

What the program accesses

It requests two Gmail permissions and one Google Sheets permission, and uses each for a narrow purpose:

  • Send mail — to email a report from the owner's account to that same account. The sender and the recipient are the same person.
  • Read mail — only to verify its own sending. After it sends a message, it looks up that specific message by the identifier Google returned, confirms the message carries the Sent label, and compares the sender, recipient, subject and body against what it meant to send. It also reads the signed-in account's address and mailbox label list to confirm it is operating on the intended account.
    The one other use: the owner's apartment community emails its monthly statement through its billing company. The program searches for those statement messages, confirms each came from that billing company, reads the attached statement to take that month's charges, and keeps a private copy of the statement on the owner's computer.
  • Google Sheets — to record each month's household rent split in the owner's own rent spreadsheet, and in a private test copy it creates in the owner's account, and to read those figures back to check them. It opens no other spreadsheet. It also reads the signed-in account's email address to confirm it is the intended account.

Apart from the statement messages described above, it does not search, list, open, or store messages. It does not read attachments, contacts, calendars, or drafts. It has no permission to modify or delete mail, and it never sends to any third party.

Where data is kept

Everything the program produces or stores stays on the owner's own computer, in a private folder readable only by the owner's user account. This includes reports, rent records, email records, and the Google authorization tokens. Nothing is uploaded to a hosted service belonging to the program, because no such service exists.

What is never done

  • No data is sold, rented, or shared with anyone.
  • No advertising, tracking, profiling, or analytics of any kind.
  • No Gmail data is used to train any machine-learning model.
  • No Gmail data is transferred to any other application or person.

How long data is kept

Reports, rent records and delivery records remain on the owner's computer until the owner removes them; the program includes a command that deletes old stored inputs. The Google authorization can be withdrawn at any time from the account's third-party access settings, which immediately ends the program's access. Deleting the program's private folder removes everything it has stored.

This site

These pages are static files hosted on GitHub Pages. They set no cookies and run no scripts. GitHub may log ordinary web-server request information as described in the GitHub Privacy Statement.

Changes

If the program's data handling changes, this page will be updated and the date above revised.

Contact

Questions about this policy can go to the support address registered on the application's Google consent screen, which is the owner's own email address.
